# Helpdesk Mockup Pro

Build the complete Helpdesk frontend UI as specified. Strictly frontend only: React/Vite JavaScript (.js/.jsx), Tailwind, shadcn/ui, React Router, TanStack Query, Axios instance prepared but no network calls, and all realistic interconnected data plus interactions handled locally through mock APIs/state. Do not create or connect any backend, database, Supabase, Firebase, server code, authentication service, external API, or integration. Implement every named route/page, responsive shell, dark mode persistence, mock protected auth/role-aware UI, filters/search, loading/error/empty states, and major local interactions. Make it polished, accessible, and populated on first launch.
